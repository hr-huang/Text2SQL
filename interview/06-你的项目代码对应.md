## 3. Reflection

**文件**：`app/workflow/orchestrator.py`（第 206-229 行）

```python
# 收集所有失败的步骤ID
failures = {r["sub_id"] for r in sub_results if r.get("error")}

if failures:
    for sq in sorted_questions:
        # 依赖失败步骤的后置步骤 → 标记跳过
        if set(sq.get("depends_on", [])) & failures:
            sub_results.append({
                "sub_id": sq["id"],
                "error": f"前置步骤失败，本步骤跳过",
            })

    # 已执行但依赖部分失败的结果 → 加警告
    for r in sub_results:
        if 依赖中有失败步骤:
            r["warning"] = "依赖的步骤已失败，本步骤结果可能不完整"
```

```python
def generate_with_tools(self, system_prompt, user_prompt, tools):
    response = self.client.chat.completions.create(
        model=self.model,
        messages=[...],
        tools=tools,           # ← 工具定义在这里传给 API
        tool_choice="auto",    # ← LLM 自己决定要不要用工具
    )
    tc = response.choices[0].message.tool_calls[0]
    return {
        "tool_name": tc.function.name,
        "arguments": json.loads(tc.function.arguments),
    }
```

## 5. LangGraph 状态图

**文件**：`app/workflow/graph.py`（第 95-196 行）

```python
def compile_graph():
    builder = StateGraph(Text2SQLState)

    # 注册节点
    builder.add_node("detect_intent", intent_node)
    builder.add_node("classify", classify_node)
    builder.add_node("decompose", decompose_node)
    builder.add_node("orchestrator", orchestrator_node)
    builder.add_node("semantic", semantic_parse_node)
    # ... 其他节点

    # 条件路由（Agent 的分叉逻辑）
    builder.add_conditional_edges(
        "detect_intent",
        route_after_intent,  # → classify 或 answer_non_data
        {"classify": "classify", "answer_non_data": "answer_non_data"},
    )

    builder.add_conditional_edges(
        "classify",
        route_after_classify,  # → decompose(complex) 或 semantic(simple)
        {"decompose": "decompose", "semantic": "semantic"},
    )

    # 循环路由（ReAct 的修复→重试逻辑）
    builder.add_conditional_edges(
        "sql_repair",
        route_after_repair,  # → execute(重试) 或 answer_exec_failed(放弃)
        {"execute": "execute", "answer_exec_failed": "answer_exec_failed"},
    )

    return builder.compile()
```

**面试要点**：StateGraph 不是 Chain——有分支、有循环、有状态回溯。

## 你的项目全景

```
用户输入
    │
    ▼
detect_intent ──(非数据)──→ answer_non_data → END
    │(数据)
    ▼
classify ──(simple)──→ semantic → schema → sql_gen → validate
    │                                                    │
    │(complex)                                   ┌───────┴────────┐
    ▼                                          成功              失败
decompose(规划)                                 │                │
    │                                           ▼                ▼
    ▼                                        answer        sql_repair(ReAct Agent)
orchestrator(执行)                                           │
    │                                              ┌─────────┴─────────┐
    ├── schema → sql_gen → validate → execute    修复成功→execute     放弃
    │       └── 失败 → 自动重试一次                          │          │
    │                                                       ▼          ▼
    ▼                                                    answer    answer_exec_failed
Reflection(检查)
    │
    ▼
merge(汇总) → END
```

**每个框对应一个文件，每种模式对应一段代码。**
